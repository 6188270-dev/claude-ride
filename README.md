# Claude Ride

3D-скейтпарк в браузере: скейтборд и самокат, трюки, комбо, станты, дрифт, 105 уровней и магазин скинов.

Играть: https://6188270-dev.github.io/claude-ride/

## Компьютер
W - разгон, A/D - поворот, пробел - прыжок, J/K/U/I/O/N/M/B/G - флипы, L/C - грэбы, Q - мэнуал, Ctrl - стант, Alt - дрифт, мышь - обзор. Полный список - в меню игры.

## Телефон (Android)
Откройте ссылку в Chrome и держите телефон горизонтально. Слева джойстик, справа кнопка прыжка и кнопки трюков, которые меняются сами. Свайп по правой части экрана - обзор.
Чтобы поставить игру как приложение: меню Chrome (три точки) - «Добавить на главный экран» или «Установить приложение». После первого запуска игра работает и без интернета.
