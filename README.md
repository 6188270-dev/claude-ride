# Claude Ride

3D-скейтпарк в браузере: скейтборд и самокат, трюки, комбо, станты, дрифт, 105 уровней и магазин скинов.

Играть: https://6188270-dev.github.io/claude-ride/

Управление: W - разгон, A/D - поворот, пробел - прыжок, J/K/U/I/O/N/M/B/G - флипы, L/C - грэбы, Q - мэнуал, Ctrl - стант, Alt - дрифт. Полный список - в меню игры.
